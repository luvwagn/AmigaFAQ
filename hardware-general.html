What are OCS, ECS and AGA?

These are the three generations of the Amiga custom chipset. OCS (Original Chip Set) shipped in the A1000, early A500s and A2000s. It can display up to 32 colours from a palette of 4,096, or all 4,096 at once in the special HAM mode.

ECS (Enhanced Chip Set) added more memory addressing and new screen modes, mainly useful for productivity. AGA (Advanced Graphics Architecture), in the A1200, A4000 and CD32, raised the palette to 16.8 million colours with up to 256 on screen at once (and far more in HAM8 mode).

What is the difference between Chip RAM and Fast RAM?

Chip RAM is memory the custom chips can reach directly, so it holds graphics and sound data. The processor has to share it with the chips. Fast RAM can only be used by the processor, so programs run faster from it because they never wait for the custom chips.

Adding Fast RAM is one of the most noticeable upgrades for an A500 or A1200.

Which processors did Amigas use?

All Amigas use Motorola 68000-family processors. The A500, A600 and A1000 use a 68000 at about 7MHz. The A1200 and CD32 use a 68EC020 at 14MHz, the A3000 a 68030, and the A4000 either a 68EC030 or a 68040.

Accelerator cards can add a faster 68030, 68040 or 68060. Some modern accelerators use FPGA or Raspberry Pi technology instead of an original Motorola chip.

In the late 1990s, Phase 5's PowerUP accelerators, the Blizzard PPC for the A1200 and the CyberStorm PPC for the A3000 and A4000, added a PowerPC processor alongside a 68k one, so software written for PowerPC could run on classic Amigas. Later, PowerPC became the main processor for newer Amiga-compatible computers such as the AmigaOne range, which run AmigaOS 4.

How do I connect an Amiga to a modern monitor or TV?

Amigas output 15kHz analog RGB through a 23-pin video port. Classic Commodore monitors such as the 1084S display this directly, but most modern monitors and TVs do not.

Common solutions are a scan doubler or flicker fixer (fitted inside the Amiga) or an external upscaler that converts the RGB signal to VGA or HDMI. The A500 and A2000 also have a composite output, but it is monochrome; the A1000, A600 and A1200 have colour composite output, though the picture quality is lower than RGB.

What floppy disks does the Amiga use?

Standard Amiga drives use 3.5-inch double-density disks, formatted to 880KB, more than a PC fits on the same disk. High-density drives (in some A3000 and A4000 models) store 1.76MB.

From Workbench 2.1 onward, the CrossDOS tool lets an Amiga read and write PC-formatted disks.

Can I still upgrade an Amiga today?

Yes, and more options exist now than ever. The community produces memory expansions, accelerators, IDE and network adapters, floppy emulators, video upgrades and replacement parts such as power supplies and cases.

Popular modern examples include Raspberry Pi based accelerators like the PiStorm, open-source accelerator designs, and FPGA-based boards. Check that an upgrade suits your exact model and board revision before buying.
